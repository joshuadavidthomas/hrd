## [0.1.0]

### Added

- A terminal picker for local Herdr sessions and sessions running in Sprites.
- Sprite discovery, creation, waking, and remote Herdr session management.
- Native Sprite terminal and SSH attachment, including SSH agent and 1Password support.
- Prompted Herdr installation in Sprites.
- Herdr config sync with `never`, `install`, and `open` policies.
- Linux and macOS binaries for amd64 and arm64, available through the install script, Homebrew, GitHub releases, and `go install`.
- Release checksums and GitHub build-provenance attestations.
